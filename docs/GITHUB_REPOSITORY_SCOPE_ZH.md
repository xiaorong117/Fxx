# GitHub仓库范围说明

本仓库对应`bubble_dissolution_solver_amgx`软件工程本身，不是算例归档仓库。

## 进入仓库的内容

- `src/`、`include/`：气泡溶解孔隙网络模型的C++求解器、Newton/AD残量、网络、输出和线性后端代码；
- `tests/`：C++和Python单元/回归/输出审计测试；
- `scripts/`：构网、单位审计、虚拟边界、重启、分析和只读监控所需的辅助程序；
- `configs/`：通用模板、物理/数值示例和AMGX配置；带有具体机器绝对路径的批量/生产/恢复配置不提交；
- `docs/`：操作手册、物理实现文档、控制方程更新文档和69例统计分析报告；
- `CMakeLists.txt`、`README.md`、许可证和第三方依赖说明。

## 明确不进入仓库的内容

- `output/`下的生产、验证、pilot、checkpoint、VTK/PVD、diagnostics和日志；
- 原始PNM、饱和度历史、派生PNM和几何输入；
- 批量算例清单、逐算例生成配置和运行锁；
- 本机控制令牌、密码、SSH凭据、构建目录和Python缓存。

这些数据规模大、含有机器绝对路径或属于不可覆盖的科学证据。需要复现实验时，应从外部受控数据目录提供PNM和配置模板，并将结果保存到仓库外的`output/`目录。

## 复现原则

1. 先编译`src/`和`include/`中的C++求解器；
2. 使用`configs/`中的模板和用户自己的PNM输入；
3. 运行`tests/`中的软件测试；
4. 在仓库外生成算例和结果；
5. 不把运行结果或原始输入复制回源代码仓库。

GitHub仓库中的统计报告只保存分析方法、汇总数字和图件引用；原始算例证据仍以服务器上受保护的机器可读目录为准。
